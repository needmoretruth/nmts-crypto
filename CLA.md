## How you agree

Write this in your pull request — in its description or in a comment on it — or on the issue you
send the code in:

> I have read the Contributor License Agreement and I agree to it.

That sentence, and the account it came from, is the whole record. **No signature, no legal name, no
address, no form.** The same agreement covers every needmoretruth repository — not this one, all
of them, including ones that do not exist yet — so once is enough, ever.

⭐ **The description is the better place**, and it is one command either way. GitHub has no way to
delete a pull request, so a sentence in its description stays put; a comment can be deleted by
whoever wrote it. Either is accepted.

## How this differs from the original

The base is the Apache Software Foundation's Individual Contributor License Agreement v2.2. Its
sections 1 to 8 appear above word for word, with these changes and no others:

1. **The counterparty is us, not the Foundation.** Every occurrence is replaced, including the
   opening paragraph that defines it, and one pronoun follows: "sent to us or **its**
   representatives" reads "our representatives". In that opening paragraph, one more word follows
   from the way you agree here: an agreement "signed by each Contributor" reads "agreed to by each
   Contributor".
2. **One sentence is removed** from the paragraph before section 1: the Foundation's promise not to
   use contributions contrary to its nonprofit status and bylaws. It describes an organisation we
   are not. Google's version of this agreement removes the same sentence.
3. **The corporate agreement is not mentioned in section 4.** The original ends that section with
   an alternative — that your employer has signed a separate corporate agreement. There is no
   corporate agreement here, so the route is your employer's permission or their waiver.
4. **The paper form is gone.** The original is a PDF asking for a full legal name, a residence
   address, a country, an e-mail address and a signature, and states that the starred fields become
   part of a public profile. None of that is asked for here, and the instruction to email a signed
   copy to the Foundation's secretary goes with it. The section "How you agree" above takes its
   place, and it is ours, not the Foundation's.
5. **Section 9 is added**, and it is the only numbered term here that is not the Foundation's. It is
   from Microsoft's Contribution License Agreement, which Microsoft placed in the public domain.

One thing that looks like a difference is not one: the original is a PDF in which "NON-INFRINGEMENT"
falls across a line break, and it is one word here.
