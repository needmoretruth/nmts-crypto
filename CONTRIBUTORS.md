# Contributors

Everyone whose code is in this program, besides the person who started it.

The list is by the account the contribution came from. **No legal names, no addresses** — the
account is the record, and that is deliberate: the
[Contributor License Agreement](CLA.md) asks for nothing more than a line saying you agree to it.

A name is added when a change lands, not when a pull request is opened.

⚠ This file is written where the code is written and copied here, so a line added to the copy in
this repository would be overwritten by the next export. Nobody has to add their own line: it is
added with the change.
